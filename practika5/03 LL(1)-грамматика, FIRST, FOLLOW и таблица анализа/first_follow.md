# Множества FIRST и FOLLOW для LL(1)-грамматики

| Нетерминал | FIRST | FOLLOW |
| --- | --- | --- |
| `S` | { `a`, `b`, `c`, `d`, `e`, `f` } | { `$` } |
| `E` | { `(`, `-`, `0`, `1`, `a`, `b`, `c`, `d`, `e`, `f` } | { `)`, `$` } |
| `Q` | { `+`, `-`, `ε` } | { `)`, `$` } |
| `T` | { `(`, `-`, `0`, `1`, `a`, `b`, `c`, `d`, `e`, `f` } | { `)`, `+`, `-`, `$` } |
| `R` | { `*`, `/`, `ε` } | { `)`, `+`, `-`, `$` } |
| `U` | { `(`, `-`, `0`, `1`, `a`, `b`, `c`, `d`, `e`, `f` } | { `)`, `*`, `+`, `-`, `/`, `$` } |
| `F` | { `(`, `0`, `1`, `a`, `b`, `c`, `d`, `e`, `f` } | { `)`, `*`, `+`, `-`, `/`, `$` } |
| `V` | { `a`, `b`, `c`, `d`, `e`, `f` } | { `)`, `*`, `+`, `-`, `/`, `=`, `$` } |
| `N` | { `0`, `1` } | { `)`, `*`, `+`, `-`, `/`, `$` } |
| `D` | { `0`, `1`, `ε` } | { `)`, `*`, `+`, `-`, `/`, `$` } |
