# 9. Программа рекурсивного спуска и тестовые примеры

Программа `recursive_descent_variant1.py` содержит лексический анализатор и набор взаимно рекурсивных процедур `program`, `assignment`, `expression`, `term`, `unary`, `factor`. Возврат к уже прочитанным токенам не используется.

## Запуск

```bash
python3 recursive_descent_variant1.py "a=0b101;b=0o17+10"
python3 recursive_descent_variant1.py --self-test
```

## Тесты

| № | Входная цепочка | Ожидаемый результат | Проверяемая особенность |
|---:|---|:---:|---|
| 1 | `a=0b101` | Accepted | двоичная константа |
| 2 | `ab=0o17+10` | Accepted | имя из двух символов, восьмеричная и десятичная константы |
| 3 | `x=-0b1*(y+2)` | Accepted | унарный минус, приоритет и скобки |
| 4 | `a=1;b=0o7;c=a+b` | Accepted | последовательность трех выражений |
| 5 | `zz=(0b10+0o3)/5` | Accepted | три системы счисления и деление |
| 6 | `q=--10` | Accepted | два последовательных унарных минуса |
| 7 | `abc=1` | Rejected | имя длиннее двух символов |
| 8 | `a=0b102` | Rejected | цифра `2` недопустима в двоичной константе |
| 9 | `a=0o8` | Rejected | цифра `8` недопустима в восьмеричной константе |
| 10 | `a=(1+2` | Rejected | отсутствует закрывающая скобка |
| 11 | `a=1+` | Rejected | отсутствует правый операнд |
| 12 | `a=;b=2` | Rejected | отсутствует выражение после `=` |

Фактический протокол запуска сохранен в [test_results.txt](./test_results.txt). Все 12 ожидаемых результатов совпадают с результатами программы.
