# 8. Формальное доказательство принадлежности грамматики рекурсивного спуска классу LL(1)

## Лексические терминалы

- `id` — имя переменной из 1–2 латинских букв;
- `bin` — двоичная константа вида `0b[01]+`;
- `oct` — восьмеричная константа вида `0o[0-7]+`;
- `dec` — десятичная константа вида `[0-9]+`;
- остальные терминалы: `=`, `;`, `+`, `-`, `*`, `/`, `(`, `)` и `$`.

## Грамматика рекурсивного спуска

```text
P  -> A R
R  -> ; A R | ε
A  -> id = E
E  -> T Q
Q  -> + T Q | - T Q | ε
T  -> U M
M  -> * U M | / U M | ε
U  -> - U | F
F  -> ( E ) | id | bin | oct | dec
```

## Множества FIRST

```text
FIRST(P) = FIRST(A) = { id }
FIRST(R) = { ;, ε }
FIRST(E) = FIRST(T) = FIRST(U) = { -, (, id, bin, oct, dec }
FIRST(Q) = { +, -, ε }
FIRST(M) = { *, /, ε }
FIRST(F) = { (, id, bin, oct, dec }
```

## Множества FOLLOW

```text
FOLLOW(P) = { $ }
FOLLOW(R) = { $ }
FOLLOW(A) = { ;, $ }
FOLLOW(E) = FOLLOW(Q) = { ), ;, $ }
FOLLOW(T) = FOLLOW(M) = { +, -, ), ;, $ }
FOLLOW(U) = FOLLOW(F) = { *, /, +, -, ), ;, $ }
```

## Проверка критерия LL(1)

Для нетерминала `R` множества `FIRST(;AR) = { ; }` и `FOLLOW(R) = { $ }` не пересекаются. Для `Q` множества первых символов трех альтернатив равны `{ + }`, `{ - }`, `{ ε }`, причем `FOLLOW(Q) = { ), ;, $ }` не содержит `+` и `-`. Для `M` получаем `{ * }`, `{ / }`, `{ ε }`, а `FOLLOW(M) = { +, -, ), ;, $ }` не содержит `*` и `/`.

Для `U` множества `FIRST(-U) = { - }` и `FIRST(F) = { (, id, bin, oct, dec }` не пересекаются. У `F` первые символы всех пяти альтернатив попарно различны. У остальных нетерминалов имеется по одной продукции.

Следовательно, для любой пары альтернатив одного нетерминала множества FIRST не пересекаются; для ε-альтернатив дополнительно выполнено условие `FIRST(α) ∩ FOLLOW(A) = ∅`. Таблица предсказывающего анализа однозначна, поэтому грамматика принадлежит классу LL(1), а реализующий ее анализатор является методом рекурсивного спуска без возврата.
